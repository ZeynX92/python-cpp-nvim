#  Конфигурация NeoVim для Python и C++
## Установка
### Arch Linux
1) `yay neovim` - установите сам NeoVim
2) `git clone https://github.com/ZeynX92/python-cpp-nvim.git` - скопируйте файлы конфигурации
3) `mkdir ~/.config/nvim` - создайте папку конфигурации NeoVim
4) `mv python-cpp-nvim/* ~/.config/nvim/` - перенесите все файлы конфигурации в созданную директорию
5) `yay python-lsp-server` - установите LSP сервер для python
6) `yay clang` - установите LSP сервер для C++
7) `yay autopep8` - установите допольнительный модуль для python-lsp-server, чтобы автоформатирование по PEP8 работало корректно
8) Зайдите в NeoVim `nvim .` и в COMMAND режиме используйте `:PlugInstall`, после перезагрузки ваш NeoVim готов к работе.
